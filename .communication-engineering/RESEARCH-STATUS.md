# Communication Engineering Research Status

This file prevents the operational briefing from overstating the evidence.

## Current overall status

Communication Engineering has:

- a coherent candidate theory of conditional fit;
- a purpose-specific outcome architecture;
- a substantial comparative corpus across technical, scientific, legal, literary, cultural, and procedural communication;
- explicit ethical, accessibility, authority, translation, and cultural boundaries;
- internal research artifacts and measurement proposals.

It does **not** yet have enough participant evidence to claim:

- a universally validated communication methodology;
- validated writer-to-purpose selection rules;
- a universal explanatory progression taxonomy;
- a causal AI strategy selector;
- a distinct scientific discipline with demonstrated boundary from neighboring fields.

## Supported foundations suitable for operational use

The current evidence is strong enough to use the following as bounded decision criteria:

1. Communication effectiveness is conditional on purpose, audience/task/context, and constraints.
2. Purpose should determine the primary outcome measure.
3. Readability, liking, engagement, confidence, brevity, and trust are not universal success proxies.
4. Architecture/reasoning structure should be selected before surface style.
5. Proof obligation changes communication structure.
6. Claim, evidence, inference, uncertainty, and authority should remain distinguishable where material.
7. Audience models should be task-relevant rather than identity stereotypes.
8. Consequential influence should preserve material alternatives, uncertainty, and autonomy.
9. Accessibility is a constraint on acceptable communication, not merely a secondary score.
10. Communication functions can sometimes transfer across sources; identity and situated authority do not transfer automatically.
11. Translation, cultural authority, sacred/restricted material, and circulation rights can limit responsible transfer.
12. Objective and subjective outcomes should be measured separately when both matter.

## Supported working operational finding

Two prospective same-model brief-construction experiments now support a selective preflight pattern:

- internal leadership update: ordinary 5/10 vs Communication Engineering 10/10;
- external customer notice: ordinary 6.5/10 vs Communication Engineering 10/10.

In both cases, the Communication Engineering condition identified all preregistered missing decision-relevant communication inputs using four grouped questions, with no guardrail failures or redundant known-fact questions.

This supports **selective preflight for underspecified communication requests**.

It does **not** establish:
- improved reader comprehension;
- improved task completion;
- controlled cross-model reproducibility;
- human-team productivity gains;
- justification for always-on context injection.

### Independent-model validation status

Controlled independent-model replication was attempted through GitHub Copilot CLI.

The target Claude model was unavailable. Copilot auto-routing then produced a reproducible confound:

- ordinary condition -> `mai-code-1.1-flash`;
- Communication Engineering condition -> `gpt-5.6-luna`.

This occurred with both full and compact context treatments.

Those runs were invalidated and not scored.

The result strengthens a tooling constraint: stable Communication Engineering semantics should move into deterministic code rather than depend on large ambient prompt context.

Experiments 01-03 remain important counterevidence: when the communication brief was already strong, the full context produced no measured correctness gain.

## Provisional strategies

These may be used as candidate structures when the communication contract supports them, but they must not be presented as validated universal rules:

- familiar case -> causal mapping -> evidence -> objections -> synthesis;
- primitives -> target -> ordered transformation -> explicit warrants -> closure;
- narrow question -> governing warrant -> effect -> action;
- experienced problem -> failed alternatives -> compact method;
- scope -> canonical terms -> layered abstraction -> normative rules -> examples/exceptions;
- linear overview + reference layer for mixed expertise;
- bounded literary functions such as omission, countervoice, motif, reversal, witness, and generative drafting.

Current support is primarily comparative textual/corpus analysis plus bounded measurement work.

## Open research

Do not operationalize these as deterministic rules yet:

- automated strategy optimization;
- writer/persona selection;
- universal audience classification;
- universal communication quality score;
- universal progression taxonomy;
- automatic cultural-transfer scoring;
- automatic persuasion optimization.

## Rejected or prohibited inferences

Current research explicitly argues against:

- identity category -> communication style;
- famous writer -> universally effective voice;
- English translation -> transparent preservation of source-language form;
- public availability -> unrestricted cultural transfer;
- engagement -> comprehension;
- liking -> effectiveness;
- readability -> understanding;
- confidence -> correctness;
- prestigious tone -> authority;
- vivid analogy -> empirical proof.

## Validation still needed

Priority evidence gaps include:

- independent second-rater validation of explanatory progression;
- named-audience procedural feasibility/pilot work;
- controlled architecture comparisons;
- audience comprehension/transfer measurements;
- cultural/community review for situated-authority transfer;
- translation-aware comparison;
- replication across models and human communicators;
- evidence on context/token cost for AI-assisted use.

## Operational rule

When a recommendation depends mainly on provisional research:

- say so;
- keep the choice reversible where possible;
- explain the mechanism being tested;
- do not hide uncertainty behind polished prose;
- prefer audience testing for consequential use.

## Promotion rule

A research finding should move from provisional to operational only when:

- the claim is scoped;
- the relevant outcome is defined;
- counterevidence has been considered;
- behavioral or equivalent task evidence exists where the claim is behavioral;
- known ethical/accessibility/authority boundaries are explicit;
- the promotion does not turn a contextual pattern into a universal rule.
