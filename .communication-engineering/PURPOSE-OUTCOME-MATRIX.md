# Communication Purpose and Outcome Matrix

This matrix is an operational projection of current Communication Engineering research.

It is deliberately purpose-specific. Do not combine these outcomes into one universal communication-quality score.

| Purpose | Primary outcome candidate | Critical failure examples | Useful secondary measures | Evidence status |
|---|---|---|---|---|
| Inform | Accurate comprehension of material claims | False belief, omitted material qualifier, confusion between fact and inference | Readability, recall, confidence | Supported foundation |
| Explain | Accurate mental model with calibrated confidence | Can repeat words but cannot explain mechanism; overconfidence in uncertain claim | Recall, satisfaction, reading time | Supported foundation |
| Instruct | Unassisted correct task completion | Critical execution error, hidden prerequisite, unsafe recovery | Time on task when mission-relevant, workload, satisfaction | Supported foundation |
| Warn | Correct recognition of risk and protective action | Missed hazard, wrong action, delayed action when delay matters | Noticeability, recall, perceived severity | Supported foundation |
| Teach | Delayed transfer to a relevant novel case | Memorized example without transfer | Immediate quiz, confidence, engagement | Supported foundation; transfer measurement remains context-dependent |
| Support a decision | Decision quality relative to stated evidence and values; traceable tradeoff recognition | Material option/risk omitted; rationale disconnected from evidence; false certainty | Confidence, decision time, satisfaction | Supported foundation |
| Coordinate | Shared operational state and correct next actions | Different readers infer different owners/state/next steps | Retrieval speed, message length | Supported foundation |
| Specify / standardize | Interpretation agreement and interoperable implementation | Normative ambiguity, conflicting interpretations, missed exception | Retrieval success, implementation time | Supported foundation |
| Build warranted trust | Confidence calibrated to actual reliability and limits | High trust in unreliable source; low trust caused by hidden uncertainty/commitments | Liking, warmth, perceived credibility | Supported foundation |
| Ethical persuasion / advocacy | Informed autonomous change consistent with visible evidence, alternatives, and consequences | Manipulative omission, coercion, hidden conflict, false authority | Engagement, memorability, attitude change | Supported foundation as constraint model; causal strategy selection remains provisional |
| Relational communication | Accurate recognition, repair, autonomy, or trust appropriate to relationship | Misrecognized intent, coercive reassurance, false commitment | Warmth, liking, perceived empathy | Provisional operationalization |
| Experiential / literary | Intended experience, reflection, recognition, ambiguity, or memory | Mechanism frustrates the declared experience or is misapplied to safety/operational task | Engagement, recall, aesthetic response | Provisional; highly context-dependent |

## How to use the matrix

1. Choose the dominant purpose.
2. Name the primary outcome before drafting.
3. Identify critical failures.
4. Select secondary measures only if they illuminate tradeoffs.
5. If multiple purposes matter, choose one dominant outcome and treat the others as constraints unless the task truly requires a multi-outcome design.
6. Do not average unlike outcomes into one score without a defensible measurement model.

## Important distinctions

### Comprehension is not readability

A readable text can still create the wrong mental model.

### Task completion is not speed

Fast failure is not successful instruction. Time becomes primary only when timing is part of the mission.

### Trust is not credibility tone

Warranted trust requires calibration to actual reliability and limits.

### Persuasion is not conversion at any cost

Ethical influence retains relevant alternatives, uncertainty, consequences, and audience autonomy.

### Teaching is not immediate recall

Transfer matters when the goal is reusable knowledge.

## Status language

- **Supported foundation:** convergent enough for bounded operational use.
- **Provisional:** useful working model requiring more behavioral validation.
- **Open research:** do not operationalize as a rule yet.
