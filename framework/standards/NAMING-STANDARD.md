# Naming and Identifier Standard

This scaffold-era document is retained for provenance. New records follow
[`IDENTIFIERS.md`](IDENTIFIERS.md), which permits parallel-safe hexadecimal
tokens while retaining four-digit legacy sequences.

Legacy identifier format:

`<PREFIX>-<AREA>-<YYYY>-<SEQUENCE>`

Examples:

- `RP-VE-2026-0001`
- `JR-HN-2026-0012`
- `EV-CLARITY-2026-0044`
- `HY-FE-2026-0007`

Recommended artifact filename:

`<identifier>--<short-kebab-title>.md`

Do not use filenames as the sole identity of an artifact.
